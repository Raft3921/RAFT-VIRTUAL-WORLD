# Right-mouse and ZL aiming — ads116

Right mouse holds an independent aiming input. The existing standard Gamepad aim binding (button 6: Nintendo ZL / Xbox LT / PlayStation L2) shares the same presentation across every firearm. Saved controller remaps and hold/toggle preferences remain intact. Mouse and controller aiming sources do not clear one another when firing is released. The existing sniper left-hold/release behavior remains when no independent aim input is active; while right mouse or ZL is aiming, the sniper fires on the attack press.

All firearms now blend from the shoulder camera into first-person sight alignment, with weapon-specific field of view and a distinct aimed reticle. Sniper lens magnification remains in WebGL and software mode retains its direct zoom and reticle. Non-sniper aiming does not add a lens render pass. Aimed movement suppresses sprint and existing precision look sensitivity applies. Weapon/viewmodel sway uses the same smooth aim blend. Melee weapons, menus, incapacitation, mantle and spectators cannot aim; cancellation and loss of focus release aiming. Unlocked/software mouse controls support simultaneous right-button aim, left-button fire and drag-to-look.

This release changes client presentation/input only and retains hit115 server synchronization. No tests, runtime checks or browser verification were performed, following the user's prior instruction.
