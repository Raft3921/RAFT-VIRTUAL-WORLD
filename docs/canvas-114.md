# WebGL非対応ブラウザー向け互換描画 · vrs-canvas114

2026-10-17。PS4実機で「WebGLを利用できません。iOSとSafariを更新してください」と表示されたとの報告に対応する。

## 原因と変更

以前はWebGL2・WebGLの両方が使えないと起動を中断し、端末を区別せずiOS向けエラーを表示していた。PS4向けのソニー資料ではWebGL 1、WebGL 2、Gamepad、Pointer Lock、Web Audioなどが非対応に分類されている。一般のWebサイトがそれらを有効化することはできない。

ソニーの資料（検索インデックス掲載内容。元URLはアクセス時に別ページへ転送される場合がある）：
https://www.sie.com/content/dam/corporate/jp/guideline/PS4_Web_Content-Guidelines_e.pdf

通常のWebGL2、WebGL1、experimental-webglのコンテキストを実際の描画canvasで順に取得する。利用できない、初期化が失敗する、またはWebGL1で必要なインスタンシング拡張がない場合は、Canvas 2Dのソフトウェア3Dへ自動移行する。`?graphics=canvas`で明示的に選択することもできる。誤ったiOS/Safari更新の案内は削除。

## 互換描画

既存のThree.jsシーングラフ・実際のカメラ・geometry・インスタンスの行列を使って三角形を画面へ投影する。視錐台・距離のカリング、6面クリッピング、深度バッファ、UVの透視補間、スキンなどの画像テクスチャ、透過と簡単な陰影を実装。別の2Dゲームや録画ではなく、同じワールドの簡易3D表示。

移動、物理、サーバー同期、銃撃、リロード、当たり判定の既存処理を使う。ソフトウェア描画専用の上限は最大24 FPS、通常384px程度の内部幅、最大512px、約170mの描画距離、通常22,000三角形／フレーム。これは処理の上限設定であり、実機で達成したFPSではない。予算を超えた形状は省かれる場合がある。

草の大量生成、高分割の遠景地面、カスタムGLSL、動的な影、魚眼・ボケ・ブラー、鏡の奥の映像、TVへの3D中継映像などは省略。鏡の移動はクラシック方式へ切り替え、ユーザーの保存設定は書き換えない。狙撃時はカメラ自体を拡大し、画面上の照準を使う。ソフトウェア描画は昼間相当の簡単な色で描く。すべてのマテリアル表現や全モデル形式を再現するものではない。

WebGLを途中まで初期化していた場合は別の表示用Canvas 2Dを用意し、元の入力canvasと重ねる。WebGLが最初から使えない場合は元のcanvasに直接描く。通常の対応ブラウザーは従来のWebGL描画を続ける。

## PS4ブラウザーでの操作

Gamepad APIがないため、PS4本体の両スティックをゲームへ直接渡すことはできない。ブラウザーの左スティックでポインターを動かし、決定で画面下のボタンを押す方式を追加。

- 前進・後退・左右移動：押すたびに開始／解除。左右と前後は組み合わせ可能。
- 停止：移動と照準を解除。
- 視点の上下左右：クリックごとに向きを変える。
- 照準：切り替え。射撃・攻撃：クリックで1回。装填・ジャンプ・しゃがむ・使う・メニューも選択可能。
- 脱落後もメニュー・観戦対象の切り替えを利用可能。
- メニューや別画面へ移動したとき、非表示・フォーカス喪失時は移動と攻撃を解除。

これはブラウザーのポインター操作を利用する互換入力であり、通常のFPSと同じ両スティック操作ではない。実際のGamepad APIが利用できる端末では従来のコントローラー操作を優先する。
