# コントローラー操作 · 2026-10-17

公開クライアント vrs-pad112。ブラウザーの標準 Gamepad API を利用し、PCとスマホで同じ入力を扱う。接続後、一度ボタンを押してブラウザーに認識させる。URLは従来と同じ。サーバーの銃撃判定・弾数・リロード・移動のルールを引き続き使用する。

| 位置 | Nintendo表示 | Xbox表示 | 動作 |
| --- | --- | --- | --- |
| 左スティック | 同左 | 同左 | アナログ移動 |
| 右スティック | 同左 | 同左 | 視点・精密照準 |
| 右トリガー | ZR | RT | 射撃、近接武器・素手は押して溜めて離す |
| 左トリガー | ZL | LT | 照準（狙撃銃はスコープ） |
| 下のボタン | B | A | ジャンプ・這い上がり |
| 右のボタン | A | B | しゃがむ・立つ |
| 左のボタン | Y | X | リロード |
| 上のボタン | X | Y | 近くの物を使う（既存のE操作） |
| 左スティック押込 | L3 | LS | ダッシュ切替。スティックを戻すと解除 |
| 右スティック押込 | R3 | RS | 匍匐・立つ |
| 中央右 | ＋ | Start | メニュー。演出中は最終カットへスキップ |
| 中央左 | − | Back | 地図 |
| 十字上・下 | 同左 | 同左 | 視点切替・チャット |
| 左右ショルダー | L / R | LB / RB | 観戦切替、飛行中は押して降下・上昇 |

メニューは十字キーまたは左スティックで移動。上下で項目、左右でスライダー・選択肢を変更する。Nintendo表示ではAで決定、Bで戻る。その他はAで決定、Bで戻る。文字入力・外部の埋め込みページ・家具編集のドラッグなどは従来のタッチ／キーボード操作が必要。

「ワールド設定 → 操作設定 → コントローラー」で視点感度、照準倍率、遊び、上下反転、Nintendo/Xbox表示を端末ごとに保存できる。右スティックには微小入力を細かく動かせる応答曲線を適用し、回転量をフレームの経過時間から算出する。

利用中はタッチ移動・攻撃ボタンを隠し、画面下に操作案内を表示する。タッチ・マウス・キーボードを使うと従来の操作表示に戻る。低画質などの端末判定はコントローラーの有無で変えない。切断・非表示・フォーカス喪失・メニュー遷移・装備変更時は入力を解除し、ボタンとスティックを一度戻すまで再入力を抑止する。未認識配置は初期状態で無効で、設定から標準配置として明示的に有効化できる。

## Switch本体について

任天堂は一般向けインターネットブラウザーを非対応と案内している。DNS経由の接続画面がGamepad API、WebGL、現在のサイトで使うJavaScriptに対応するかは未確認。DNSでページを開けることと、このゲームを本体で実行・操作できることは別途確認が必要。サイト側でブラウザーにないAPIを有効化することはできない。入力APIが存在しない場合は未対応を表示する。

- 任天堂: https://support-jp.nintendo.com/app/answers/detail/a_id/34190
- Gamepad API: https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API

既存のユーザー指定に従い、テスト・構文検査・実行確認・ブラウザー検証・実機確認は実施していない。実際のSwitch、スマホ、各コントローラーの配置、操作感、性能は未確認。
