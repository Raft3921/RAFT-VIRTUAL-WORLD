# 操作の改良 · vrs-pad113

2026-10-17。コントローラーの動作仕様はこの文書がcontroller-112.mdの該当部分を更新する。PC・スマホの対応ブラウザー向け。Switch本体・PS4本体のAPI・3D描画・ブラウザーによる予約操作の互換性は未確認。

## 基本配置

| 操作 | Nintendo | PlayStation | Xbox |
| --- | --- | --- | --- |
| 移動 / 視点 | 左 / 右スティック | 左 / 右スティック | 左 / 右スティック |
| 射撃 / 照準 | ZR / ZL | R2 / L2 | RT / LT |
| ジャンプ / しゃがむ | B / A | × / ○ | A / B |
| リロード / 使う | Y / X | □ / △ | X / Y |
| ダッシュ / 匍匐 | L3 / R3 | L3 / R3 | LS / RS |
| メニュー / 地図 | ＋ / − | OPTIONS / SHARE | Start / Back |
| 視点切替 / チャット | 十字上 / 下 | 十字上 / 下 | 十字上 / 下 |
| 観戦切替・飛行の降下 / 上昇 | L / R | L1 / R1 | LB / RB |

タクティカル配置は「しゃがむ」と「匍匐」を交換。右スティック押込でしゃがめる。近接武器とパンチは射撃ボタンを押して溜め、離して攻撃。銃の連射・発射間隔・リロード・弾数は既存の武器とサーバーの規則を使う。

## 設定への入口

ポーズメニューの「コントローラー設定」から直接開く。従来のワールド設定 → 操作からも開ける。設定はこのブラウザープロファイルに保存する。

- Nintendo・PlayStation・Xboxの表示をIDから選択。誤認識時は手動で変更。
- メニューの決定を下または右のボタンに変更可能。戻るはもう一方。
- 各アクションの変更ボタンを押し、割り当てるボタンを10秒以内に一度押す。既存操作と重複する場合は交換。割り当て中はゲーム・メニューの操作を実行しない。キャンセルまたは時間切れで終了。
- 標準・タクティカル配置のボタンで割り当てを戻せる。感度などの好みは維持。
- 視点感度、縦方向の倍率、照準感度、上下反転、左右それぞれのスティックの遊び、応答曲線、任意の視点平滑化を変更可能。
- 照準は長押しまたは押すたびに切替。ダッシュは開始ボタン、長押し、自動から選択。照準中はダッシュしない。
- 「入力の状態を見る」に軸の値、押したボタンの番号・名称、mappingを表示。ユーザー自身による配置やドリフト確認のための画面であり、外部への送信や自動試験はしない。

## メニュー

十字キーと左スティックは画面上の配置に沿って項目を選ぶ。スライダー・数値・選択欄では左右で値を変更。左右ショルダーは前後の項目へ順番に移動し、端で折り返す。右スティック上下でスクロール。ボタン・チェック欄・detailsの見出しは決定で操作できる。文字入力と外部iframe内の操作は従来の入力が必要。

## 入力の扱い

- スティックの外周付近を最大入力にして、小さな到達差で最大速度が出なくなることを減らす。
- トリガーは浅い押し込みから入力。解除しきい値を別にし、境界付近の押し直しを抑制。
- メニュー・装備変更・切断などで攻撃と照準を解除。移動と視点は再開可能な状態になれば使える。移行時に押していたボタンだけは離すまで無効にして、誤射やメニューの即時再オープンを防止する。
- マウス・タッチ・キーボードに切り替えると、パッドからの攻撃・照準を解除して従来UIへ戻す。
- 旧WebKit形式のgetGamepadsと数値形式のボタンを読み取る。mappingがstandardでない機器は利用者が標準配置利用を有効化する必要がある。任意の軸配置の自動補正や、ブラウザーが予約した操作の解除を保証するものではない。

既存の指示に従いテスト・構文検査・実行確認・ブラウザー・実機検証は行っていない。操作感・全端末の互換性は未確認。クライアント変更のみでサーバーの判定や同期プロトコルは変更しない。
