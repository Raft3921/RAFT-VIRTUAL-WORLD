## 最新のゲーム変更

- ロケットの爆風半径は12mから8.4m（70%）へ縮小。通常の爆発・最終ヒットリプレイとも共有の半径を使う。爆風の対象は部位OBBまでの距離に加え、着弾点から最寄りの部位表面または中心への遮蔽判定を必須とし、壁・屋根・床・閉じた扉等の向こうへダメージを通さない。破壊可能な遮蔽物も、当該爆発の対象選択時点では遮断する。
- 大型マップの一部領域で攻撃がライフに反映されない原因を修正：`GunRules.damage` が既定の砂マップの範囲を参照していた。参加者情報と選択中のマップで判定し、弾・刀の対象選択も選択中のマップに統一。報告された無敵症状すべての解消は実機未検証。Worker/LAN共通処理。ゲームのテスト・構文チェック・ブラウザ確認は実行していない。
- スナイパーを構えている間のマウス感度は、設定されている通常感度の50%（縦・横とも）。構え解除で通常に戻る。タッチと他の銃の照準感度は従来の24%を維持。ゲーム動作は未検証。

一括公開ツール追加前の最後のゲーム変更は `f148980` / `vrs-mantle135`。当時 Worker と両 Pages ジョブ成功、公開 `release.json` 一致を確認。ゲーム実機は未検証。

- カメラは前転・バク宙・横宙返り・壁走りに追従回転しない。ユーザーが一度カメラ回転を希望した後、明確に撤回した。再導入しない。
- 一人称の胴・脚は**後ろ側**へ描画時だけ下げる。前へ出した変更はユーザーが逆だと訂正。物理 root、他プレイヤー、鏡の姿、命中判定へこの表示補正を適用しない。匍匐中の自分の身体は非表示、武器の別描画は維持。
- 前入力＋ジャンプで前宙返り、後ろでバク宙、左右で横宙返り。着地や姿勢入力で回転が途中解除されない。スライドジャンプは2回前宙返り＋通常の2倍の高さ（上向き初速は sqrt(2) 倍）。
- 壁を手で登り続ける動きではなく、足を壁につけ身体を90度傾ける壁走り。入力に応じ縦・横・斜めへ走る。通常の壁走りは1面2.4秒、空中の蹴り回数6まで。
- 壁走り中のジャンプは壁法線方向へ通常の2倍の蹴り出し初速（現在16.8 m/s）。横の接線成分を足さず、直前の上下速度を引き継ぐ。これは世界の上向き高さ2倍という意味ではない。壁走りの向きで連続バク宙し、落下中に傾きが戻り、着地前に最後の全回転を収める。カメラは回らない。
- 銃を装備すればゾーン外でも共有アクションを使う。屋内 Shift はダッシュ、空中ジャンプは飛行切り替えに取られない。刀だけのゾーン外は元の通常移動。座る・眠る・料理・生活アクティビティ・飛行・ラグドール等には別の制御がある。

- 自動よじ登り：空中で届く屋根・塀を検出し、スペースの押し直し不要。回転中は完了優先。`mantle135` は壁法線方向も探索し、近距離の視線角度条件を緩め、薄い壁上では足を中央に支持させる。屋根の張り出しは14–56 cm下がる経路も試す。全経路と頭上を衝突確認。届く屋根では壁蹴りよりよじ登り優先。発動のしやすさは未検証。

## 壊さない共有構造

- `player-physics.js` / `world-collision.js`：共有移動・衝突・重力。`combat-movement.js`：装備による有効化、ダッシュ、スライド。`player-parkour.js`：壁接触とアクション状態。`player-mantle.js`：縁と退避経路の検出・経路移動。
- `server-player-physics.js`：順序付き入力の重複排除、時間予算、サーバー計算とACK。`player-prediction.js`：即時入力・未ACK入力の再実行。`movement-wire.js`：18値の圧縮入力。`SYNC_PROTOCOL` は現在3。内容が非互換になる変更は独断で同じ番号に押し込まない。
- サーバーの入場/試合テレポートは `gunTeleportSerial` の境界。`GunRules.move` で `entry.motion=null` と状態を初期化し、古い入力を拒否する。以前の「入場直後に外へ戻される」を再発させない。
- `parkour-pose.js` と `parkour-rig.js`：同じ姿勢・関節・部位寸法を描画と命中判定で共有。通常スリムとギョーザモデル対応。`avatar.js`、`gun-posture.js`、`projectile-motion.js` の三軸 OBB、`gun-hit-timeline.js` の履歴・巻き戻しがつながる。身体全体を大きな箱で包む判定に戻さない。
- `remote-motion.js`：低バッファ補間。銃撃戦の待ち時間は16–55 msの範囲で適応。相手を無制限に予測して遮蔽物を突き抜けさせない。送信60Hz目標、端数時間を繰り越す送信時計、Worker/LANの受信最小間隔8ms、銃弾tick60Hz目標。実遅延は未測定。
- `gun-cinematic.js`：発射するプレイヤー→弾追従→着弾/倒れる→俯瞰の勝敗という継続演出。スキップで俯瞰勝敗へ進める既存制御を維持。UIやカメラ回転の最新指示を優先。
- マップは砂/雪とその大型版の4種、全体設定で切替。共有形状・扉・格子を Worker と描画で共用。`settlement125` は階段の支持構造や遮蔽物、安定したダッシュ視点を改善。建物看板を復活させない。

## 公開・引き継ぎ時の確認先

`publish.command` は既存の `.room-*` 保存データや認証情報を Git に含めず、`.publish/` に結果を保存する。失敗時は「完了」と言わない。未変更の同じ HEAD を再公開する場合は `--resume`。Git merge/rebase、強制 push、失敗時の自動ロールバックは行わない。

GitHub 側には `Publish GitHub Pages` と標準の `pages build and deployment` が並んで動く場合がある。配信内容により `release.json` はプロジェクト直下か `/dist/` に現れる。コマンドが両方を調べ、対応する公開番号を確認する。`dist/dist/index.html` は従来URL用の互換リダイレクト。
