# Mac-connected Pro Controller fallback — pro119

The user supplied screenshots showing a Bluetooth-connected Pro Controller on macOS while the game reported no controller, and identified Chrome as the browser. The screenshots establish OS pairing, not why the browser's Gamepad API returned no device. This revision does not claim to identify that hardware/browser cause.

Controller settings add an explicit Pro Controller direct-connect button using feature-detected WebHID. A user click opens Chrome's device picker restricted to Nintendo 057e:2009. After selection, the adapter opens that device, performs USB initialization only if that output report exists, requests full input reports, and reads factory stick calibration without writing device memory or altering pairing. Packed stick and button data is translated into the same standard button layout used by existing gameplay. Only one chosen device is opened. Native input remains the default; successful direct input selects the adapter to prevent duplicate native/HID actions. Disconnect and page exit close the handle; stale input is neutralized after 500 ms and removed from the usable pad list. Pending command replies have bounded timeouts.

Rescan now waits up to 15 seconds for input exposure and reports browser input availability separately from OS Bluetooth state. Diagnostics show API presence, exposed native devices, direct-input reception, page focus, secure context, and permission-policy state. Unsupported browsers display the direct-connection limitation; failure to open a device displays the actual error instead of claiming a Bluetooth disconnection.

Protocol references: https://raw.githubusercontent.com/torvalds/linux/v6.12/drivers/hid/hid-nintendo.c and https://developer.chrome.com/docs/capabilities/hid . This is independent application code using report facts, not a copied driver.

No tests, browser checks or physical-controller validation were performed, following the user's earlier instruction. Actual operation with the user's device remains unverified. Client-only release; hit115 server synchronization is unchanged.
