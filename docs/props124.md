# Faster sprint response and shared town props — props124

Gun-zone sprint starts at 5.8 m/s on an aligned grounded sprint press, up from the previous 4.62 m/s target with gradual startup. The ramp from that start speed to the unchanged 7.2 m/s maximum takes 0.55 seconds instead of 1.65. Ground movement acceleration is 24 m/s² instead of 8. Releasing movement input while grounded and outside a slide immediately clears horizontal velocity and sprint charge. Slide and airborne momentum retain their existing behavior. Sprint charge is now a field computed by shared locomotion, consumed identically by server snapshots and camera effects. Mantling clears it. Authority/prediction, ordered packets and teleport barriers remain in use.

All four towns now use gun-town-props.js for detailed hinged doors and actual barred side-window openings. It emits grouped door leaves, panels, handles and hinges and grouped grille rods/crossbars, sharing logical IDs and bounds. New towns replace their solid side walls with sills, headers and posts around two barred windows per side; the grille can be broken/cut to expose an actual opening. Each building has two detailed doors and four grille groups. Snow/desert accents remain map-specific. Ground and elevated variants provide a floor height for debris so fragments settle on the raised district instead of falling to world zero.

Render geometry, movement collision, server bullet/prop definitions and round reset use the same recipe. No decorative signs are added. No tests, syntax checks, browser checks, visual checks or multiplayer verification were performed, following the user's earlier instruction.
