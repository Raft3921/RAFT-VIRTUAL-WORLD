# 銃撃戦・公園更新 — tactics99

- ブランコは連続回転できる振り子。ロープは撚り目と結び目付き。乗員も座面と同じ支点に追従。
- 銃は引き抜き・差し込みに短い動作と停止を使い、反動は速く戻る。視点旋回に最大約2度の傾き。
- 被写界深度は前景の手を除いて照準先に自動合焦。遠景のにじみ・動体ブラー・周辺減光を抑え、深度をまたいだ色漏れを防ぐ4近傍フィルター。
- マップは2.67mの窓開口、10m級の屋上、折り返し階段、曲がり角、低い遮蔽、匍匐専用の0.63m開口。階段の衝突は見た目と同じ向きの連続斜面。装飾の塀は階段の動線を避ける。
- C / リロードの下の「匍匐前進」で高さ0.48m、移動速度20%。立ち上がるには通常姿勢の占有空間が必要。姿勢は同期され、命中判定・足音・カメラにも反映。
- ドアは体当たり・射撃で開く。格子はジャンプ接触・射撃で壊れる。開放・破損・切断の状態を設定保存と同じキューで永続保存し、途中参加にも配信。閉じたり復活したりはしない。
- ボードでライフ3〜100（整数）を設定。試合中は変更不可。威力は拳銃・散弾1、マシンガン0.5、スナイパー1.5、ロケット2。
- 日本刀はストアで1コイン、勝利条件なし。長押し→離して斬る。サーバー計測で1〜5ダメージ、最大溜め約1.72秒、射程2.8m。両手の肘は体の近くに保ち、第三者視点でも肩・肘が動く。残像3枚。木箱・ドア・格子を平面で二分し、切断面のある破片を1描画にまとめる。
- 参考：熟語シリーズゲームの continuum 内の刀モーション・残像、convex-cut.ts（TypeScriptをJSへ変換）。人体切断は対象外。
- 銃撃戦ゾーンは上向き初速7.2m/s、重力9.8m/s²、落下速度上限55m/s。ジャンプ頂点は約2.64m。テントの跳躍高度は同じ入射速度のトランポリンの3倍（速度を3倍にして9倍の高度にはしない）。
